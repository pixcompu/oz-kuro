### Oz Kuro

Landing page for Oz, my black cat mascot: https://oz-kuro.com/

Static site: a single `index.html` (Spanish by default, with an English toggle), plus Oz's sticker cutouts and clips in `assets/`.
The "Oz en todas sus formas" sticker album is built from `gallery.js`; to add a pose (as a sticker or a regular photo), run `tools/album/add-to-album.sh` (see [tools/album/README.md](tools/album/README.md)) and add the entry it prints.
